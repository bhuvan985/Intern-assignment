# AI Usage

AI was used as a productivity tool for this prototype.

| Tool | What I used it for | Why I used AI | What I personally verified |
|---|---|---|---|
| ChatGPT | API structure, Flask boilerplate, frontend scaffolding, README structure | To speed up repetitive implementation work within the one-day time limit | Dataset calculations, API behavior, data-quality handling and application flows |
| ChatGPT | SQL/query and analytics suggestions | To accelerate dashboard aggregation work | Checked totals and status/course/institution counts against the supplied dataset |

I did not use AI to fabricate business insights. The numerical insights in the dashboard were calculated from the supplied synthetic dataset and manually checked.

The final implementation should be reviewed and understood by the person submitting it; AI-generated code should not be presented as code that the submitter cannot explain.
